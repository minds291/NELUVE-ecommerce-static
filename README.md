# Статическая версия NÉLUVÉ

Копия прототипа: откройте `index.html` или разместите содержимое папки на статическом веб-сервере. Для локального просмотра из этой папки можно запустить `C:\xampp\php\php.exe -S 127.0.0.1:8094` и открыть http://127.0.0.1:8094/.

Сайт не зависит от WordPress и базы данных. Каталог содержит демонстрационные товары прототипа; корзина хранится в localStorage браузера. Оформление заказа, контактная форма и подписка демонстрационные: заказ и оплата не выполняются. Некоторые ссылки остаются заглушками прототипа.
